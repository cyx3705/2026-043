# 工具链实测记录（2026-11-03）

本项目由 AI 从零完成：方案 → 选型（蚂蚁工场）→ 建模 → 装配 → 干涉/孔位核对 → 10 张加工件图。下面记录各环节实际用了什么、哪里卡住。

## 流程与用到的工具
| 环节 | 工具 | 结果 |
|---|---|---|
| 建项目 | `janus.proj.create base=0000-000-Template` | 一次成功 |
| 外购件选型与下载 | `strenua.mymooo.category/product/insert/remove` | 3 个模组、导轨、型材 4 种长度、角码、脚杯全部一次拿到 |
| 读外购件安装孔 | Python COM 遍历圆柱面 | 拿到滑台、底座的真实孔距，加工件按它开孔 |
| 加工件建模 | Python COM（草图 + 拉伸/切除 + 偏置基准面） | 10 种零件；SW MCP 只有基础草图工具，未用 |
| 装配 | Python COM（变换矩阵 + 固定） | SW MCP 的 `insert_component` 只能平移 |
| 干涉与孔位核对 | COM `InterferenceDetectionManager` + 自写孔位比对 | 发现并修掉 1 处真实干涉（立柱底板撞 X 模组电机端罩） |
| 出图 | `strenua.onekey.machined` + `dim/tech/check/view` 系列 | 8 张一键后修；2 张（08、10）一键选错主视图，改为手建主视图 + 分步指令 |

## 缺口与问题（按影响排序）
1. **一键主视图选错**：08 托板加强筋把 12 mm 厚的侧面当主视图，三角形轮廓没出现；10 升降模组安装板 1640 长竖放、1:10，Ø6.6 孔只剩 0.66 mm。`drawing.create` 没有主视图方向 / 旋转 / 比例参数，只能 COM 手建主视图后接分步指令（分步指令能正确处理旋转 90° 的视图）。
2. **螺纹孔**：模型里螺纹孔画成底孔时，孔标注显示「Ø5 ↧15」，每张都要 `dim.edit prefix=` 手改成 M6；`prefix` 会顶掉 Ø 符号，要连 Ø 一起写进前缀。
3. **背面沉孔**：一键对背面沉孔只标「Ø6.60 贯穿」，不写沉头也不写「(反面)」（01/03/04 都要手补后缀）。
4. **冗余与未标检查互相矛盾**：对称件上删掉「重标」建议的尺寸后，「未标尺寸」又报漏标（04、06），要换成对称标法（120 + 240）两边才都干净。
5. **一键作用于活动文档**：`doc.close` 关图后活动文档会跳到总装或别的零件，一键可能出到错的零件上（本次 10 号就是这样出来的）。
6. **蚂蚁工场插入的平移**：插入件被平移成包围盒居中，回执不给这个偏移；按零件原点摆位会整体错一个半长。
7. **SW 内存**：连续出 7~8 张图后 SW 私有内存涨到 14 GB，加上 WSL 的 14 GB，整机只剩 1.2 GB，Python 连类型库都加载不了，只能存盘后重启 SW。
8. **技术要求**：「机加件-有色金属」第 9 条（钢丝牙套）、第 7 条（螺纹表面）每张都要按有无螺纹手删。
9. **标题栏「设计」格**仍是空的（只有修改栏有设计者），老问题。

## Strenua 1.38.0 之后（2026-11-03 同日）
- 建模、装配不再用 Python COM 和 SW MCP：`strenua.model.*`（新建、草图、拉伸切除、基准面、删特征、模型信息含孔表）、`strenua.asm.*`（列表、带旋转插入、摆位、删除、干涉检查）。
- 螺纹孔用 `strenua.dim.thread`：本项目 02/05/06/08/09 的 6 个螺纹孔标注已改成「N x M6↧12 / 孔↧15」「M12 贯穿」；01/03/04 的反面沉孔用 `dim.edit below=` 改成两行。原来手写 Unicode「↧」「Ø」画成乱码的问题已消除（缺口 2、3）。
- 蚂蚁工场：外购件里 4 个模组 / 导轨总装原先引用 SolidWorks 临时目录（3D Interconnect 链接），已重下为真文件（零件在「外购件\料号\」），重开总装位置不变；导轨滑块重新挪到 x = −600。插入改为按零件原点摆、不再有平移（缺口 6），导入不再弹模板确认框。
- 干涉检查把零厚度贴合单独计数：总装现在只剩 FBT134 模组内部 2 处厂家模型干涉。
