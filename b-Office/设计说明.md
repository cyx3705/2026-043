# 立式货架取货机 设计说明

## 任务
在一排立式货架前沿 X 方向行走、Y 方向升降，伸出货叉（向 −Z 伸入货架）取放料箱。

## 主要参数
| 项 | 值 |
|---|---|
| 料箱 | 400（X）× 300（Z）× 200 mm，≤ 10 kg |
| X 行走 | 1200 mm，FBT134 同步带模组，4 滑块，400 W |
| 升降 | 1200 mm（软限位下限 +60 mm，见注 1），FST134 丝杆模组 2010/C5，400 W，电机朝上 |
| 货叉伸缩 | 400 mm，FST100 丝杆模组 1620，W 宽导轨，200 W 右折 |
| 货叉面高度 | 约 440 ~ 1527 mm（地面起） |
| 外形 | 1880（X）× 700（Z）× 2010（高）mm |
| 框架 | 欧标 40 槽 10 铝型材（4040、8080）+ M12 脚杯 |

## 坐标约定（总装）
原点在地面、X 行程中心；+Y 向上；X 沿货架；货架在 −Z 一侧，货叉向 −Z 伸出。
模型状态：X 滑台在左端（x = −600），升降在最高位，货叉缩回。

## 结构
1. 底架：三根 4040×700 纵梁（沿 Z，x = −920 / 0 / 920）下装 09 脚杯连接板 + M12 脚杯；上面压两根 4040×1800 横梁（z = ±47）。
2. X 轴：FBT134 平放在两根横梁上，T 形螺母固定。
3. 立柱：X 滑台上装 01 立柱底板（4×M6），竖 8080×1640 立柱（底端 2×M12），两侧 02 加强筋（侧槽 3×M8 + 底边 2×M6）。
4. 升降：10 升降模组安装板（T 槽 8×M6）贴立柱前面，FST134 用 16×M6 固定在安装板上，滑台朝货架。
5. 顶部导向：两根 4040×1865 立柱 + 4040×1800 顶梁（压铸角码连接），顶梁下装 15 规格导轨（GAHH1R，1500 长）；03 立柱顶板用 4×M12 压在 8080 顶端，后伸出 60 mm 托住导轨滑块（4×M4），防止立柱晃动。
6. 货叉：升降滑台上装 04 货叉立板（4×M6），05 货叉托板顶在立板前面（后端面 4×M6），两侧 08 托板加强筋；FST100 用 4×M6 坐在托板上，滑台上装 06 货叉板（4×M6），后侧两块 07 挡块（M5）。

## 注
1. 货叉立板下沿在升降最低位会碰立柱底板：升降下限软限位取滑台中心 ≥ 460 mm（行程实际可用约 1140 mm）。
2. 货叉只设后挡块：伸入货架时货叉从料箱底下穿过，前挡块会撞箱；缩回时惯性把箱往货架方向推，加减速要缓（≤ 0.3 g）。
3. 立柱是挂在 X 滑台上的 1.6 m 悬臂，顶部靠导轨滑块约束；X 加减速时滑块受侧向力，导轨选 15 规格已足够（静载远大于需求）。
4. 螺纹孔在模型里画成底孔（M6 → Ø5，M5 → Ø4.2，M12 → Ø10.2），出图时按螺纹标注。
